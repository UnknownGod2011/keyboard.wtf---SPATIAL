# Demo plan · 2 minutes 35 seconds

Use this shot list after each workflow passes in Interactive Preview. Record a synthetic Windows document inside a dedicated sharing rectangle. Keep personal apps, account details, credentials, notification banners and irrelevant desktop areas outside the recording.

| Time | Show | Narration |
|---|---|---|
| 0:00–0:15 | The Lens in SPECS Preview, with the shared workspace in the room | “This is keyboard.wtf SPATIAL. I can keep a Windows document beside my work and ask for help without leaving it.” |
| 0:15–0:42 | Update the document on Windows and show the corresponding live change in Preview. Move the frame and change its size. | “This is a live view of the Windows region I chose to share. I can place and size it where I need it.” |
| 0:42–1:16 | Pinch Jarvis, speak “Open Calculator,” show the transcript, confirm, and capture the resulting Calculator window | “Jarvis listens on request. I review the command before it goes to Keyboard.wtf, where the usual Windows action policy applies.” |
| 1:16–2:06 | Select and copy part of the synthetic document. Pinch Cursivis, choose Summarize, and show the real returned result | “I can share a specific selection. Cursivis gives me actions for that text, and the answer stays in the same workspace.” |
| 2:06–2:35 | Open Settings, pause the view and show the workspace's position from another angle | “One panel shows what the PC is sharing and whether the microphone and contextual actions are enabled. I can leave the window in place and turn back to my physical desk.” |

If a path fails live verification, record the tested alternative and say exactly what the viewer is seeing. Describe a typed turn as typed. Describe clipboard handoff as an explicit copy on Windows. Treat the upstream acknowledgment as a submitted turn and show the resulting Windows action before claiming completion.
